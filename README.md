# Calculator with GUI using Python

The application provides a simple graphical interface where users can enter numbers and perform basic arithmetic operations. It also includes error handling for invalid expressions and division by zero.

## Task Objective

The objective of this task was to build a functional graphical calculator application using Python.

The task involved:

1. Designing the calculator interface.
2. Implementing basic arithmetic operations.
3. Handling invalid inputs.
4. Displaying calculation results dynamically.
5. Testing the functionality of the application.

## Technologies Used

- Python
- Tkinter
- Git
- GitHub
- Visual Studio Code

## Features Implemented
The calculator interface was created using Python's built-in Tkinter library.

The interface contains:

- A calculation display
- Number buttons from 0 to 9
- Decimal point button
- Addition button
- Subtraction button
- Multiplication button
- Division button
- Equal button
- Clear button
