# Python GUI Calculator

A simple graphical calculator application developed using Python and Tkinter as part of Task 3 of my Python Development Internship at Auspify Technologies.

## Project Overview

This project is a desktop-based calculator application with a graphical user interface (GUI). It performs basic arithmetic operations and includes error handling for invalid inputs and division by zero.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal number calculations
- Clear button
- User-friendly graphical interface
- Error handling
- Division-by-zero handling
- Dynamic result display

## Technologies Used

- Python
- Tkinter

## Concepts Learned

- Tkinter GUI development
- Python functions
- Event handling
- Buttons and input fields
- Grid and Pack layout managers
- Error handling using try-except
- Lambda functions
- Basic input validation
